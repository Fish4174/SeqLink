# SeqLink
单链表学习笔记

1.用户输入链表总结点数，依此调用*CreLink()函数建表，*CreLink()函数中包含了输入结点数据的操作，函数的返回值为头结点地址；

2.根据用户需求，输入数字1~8执行如下操作：

（1）输入1，调用GetLen()函数，输出当前表长；

（2）输入2，调用GetElem()函数，取第i个元素的值；

（3）输入3，调用Locate()函数，定位第1个值为x的元素；

（4）输入4，调用Delete()函数，删除第i个元素；

（5）输入5，调用Insert()函数，在第i个元素前插入一个值为x的元素；

（6）输入6，调用List()函数，输出当前单链表；

（7）输入7，调用SwapMin()函数，将最小值移动到链表最前面；

（8）输入8，结束程序。

3.问题9（SwapMin()函数）思路：

（1）假设第一个结点是最小的（head->next）

（2）工作指针遍历链表，每个结点与当前最小结点做比较；如果发现了更小的：

（2.1）记住这个新的最小结点

（2.2）记住它的前驱，因为一会儿要摘下最小结点

（3）遍历完成后，如果第一个结点不是最小的：

（3.1）摘下最小值结点，即前驱结点的后继=最小结点的后继

（3.2）把最小值结点插入头结点的后面，即最小结点后继=头结点后继，头结点后继=最小结点
